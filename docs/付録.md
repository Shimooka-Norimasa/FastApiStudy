# 付録 次のステップ・困ったとき

## A. よくあるエラーと対処

| 症状・エラー | 原因 | 対処 |
|---|---|---|
| `uvicorn : 用語 'uvicorn' は ... 認識されません` | 仮想環境が有効になっていない | `.venv\Scripts\Activate.ps1` を実行（第0章） |
| `Error loading ASGI app. Could not import module "main"` | `main.py` があるフォルダで実行していない | `cd step06_todo_app` などで移動してから起動 |
| `TemplateNotFound: index.html` | 実行しているフォルダが違う／ファイル名の間違い | `templates` フォルダがある場所で起動しているか確認 |
| `Form data requires "python-multipart" to be installed` | ライブラリ不足 | `pip install python-multipart` |
| `[Errno 10048] ... address already in use` | 別のサーバーが 8000 番で動いている | 他のターミナルで `Ctrl + C`、または `uvicorn main:app --reload --port 8001` |
| ブラウザに `{"detail":[...]}` と 422 エラー | 型ヒントと違う値が来た、必須の値が無い | URL やフォームの `name` が引数名と一致しているか確認 |
| ブラウザに `{"detail":"Method Not Allowed"}`（405） | GET/POST の取り違え | `@app.get` / `@app.post` と `<form method="post">` を確認 |
| `The starlette.testclient module requires the httpx2 package` | テスト用ライブラリ不足（第11章） | `pip install httpx2` |
| `pytest` で `ModuleNotFoundError: No module named 'main'` | テストのあるフォルダで実行していない | `cd step11_test` などで移動してから `pytest` |
| テーブルに列を追加したのに反映されない | `CREATE TABLE IF NOT EXISTS` は既存テーブルを変更しない | `.db` ファイルを削除して再起動 |

### エラーの読み方

ターミナルに長いエラー（Traceback）が出たら、**一番下の行** を見てください。そこに本当の原因が書いてあります。

```
Traceback (most recent call last):
  File ...
  File ...
sqlite3.OperationalError: no such column: titel     ← ここを見る（列名のタイプミス）
```

## B. 用語集

| 用語 | 意味 |
|---|---|
| リクエスト / レスポンス | ブラウザ→サーバーのお願い / サーバー→ブラウザの返事 |
| GET / POST | データを取得するリクエスト / データを送るリクエスト |
| ルーティング | URL と関数を対応付けること（`@app.get(...)`） |
| パスパラメータ | URL の一部から受け取る値（`/hello/{name}`） |
| クエリパラメータ | URL の `?` 以降から受け取る値（`?a=1&b=2`） |
| JSON | `{"key": "value"}` 形式のデータ。プログラム間のやり取りでよく使う |
| テンプレートエンジン | HTML のひな形に値を埋め込む仕組み（Jinja2） |
| リダイレクト | 「別の URL を開き直して」とブラウザに指示すること |
| 静的ファイル | CSS・画像など、加工せずそのまま返すファイル |
| CRUD | Create / Read / Update / Delete の4操作 |
| SQL インジェクション | 入力値に SQL を仕込む攻撃。`?` で値を渡して防ぐ |
| XSS | 入力値に HTML/JavaScript を仕込む攻撃。Jinja2 の自動エスケープで防ぐ |

| [第12章](12_SQLModelでデータベースを扱う.md) | SQLModel（ORM）でデータベースを扱う |
| [第13章](13_ワーカーで時間のかかる処理を行う.md) | ワーカーで時間のかかる処理を行う（キューとワーカーの自作） |

応用編も終えたら、次のテーマがおすすめです。

1. **ログイン機能（認証）** … パスワードのハッシュ化、セッションや JWT によるログイン状態の管理。FastAPI 公式チュートリアルの「Security」の章が参考になる
2. **マイグレーション（Alembic）** … データを残したままテーブルの列を追加・変更する
3. **非同期処理（async / await）** … `async def` で書く FastAPI の関数と、非同期対応のデータベースライブラリ
4. **テーブルの関連（リレーション）** … 「ユーザー」と「ToDo」のように、複数のテーブルを関連付ける
5. **ワーカーのフレームワーク** … Celery、RQ、Taskiq など（第13章のコラムで紹介）。Redis の使い方もあわせて学ぶとよい
6. **公開（デプロイ）** … 作ったアプリをインターネット上のサーバーで動かす（Docker、クラウドサービスなど）

> 公開（デプロイ）する場合は、この教材のコードをそのまま使うのではなく、ログイン機能や
> CSRF 対策（他のサイトから勝手にフォームを送信される攻撃への対策）などを追加する必要があります。
> この教材は、自分の PC の中で動かして学ぶことを前提にしています。
