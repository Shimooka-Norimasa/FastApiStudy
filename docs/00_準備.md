## 0-1. Python のバージョンを確認する

```powershell
python --version
```

`Python 3.10` 以上が表示されれば OK です（この教材は 3.12 で動作確認しています）。
`python` が見つからない、またはバージョンが古い場合は [付録 Python のインストール](付録_Pythonのインストール.md) を見てください。

> Mac では `python` の代わりに `python3` と入力します（仮想環境を有効化した後は `python` で動きます）。

## 0-2. 教材を手に入れる

次のどちらかの方法で、教材一式を自分の PC に用意します。

**方法A: ZIP でダウンロード（git を使ったことがない人向け）**

1. 教材の GitHub ページ（https://github.com/Shimooka-Norimasa/FastApiStudy ）を開く
2. 緑色の「**Code**」ボタン →「**Download ZIP**」を押す
3. ダウンロードした ZIP ファイルを右クリック →「すべて展開」で好きな場所に展開する

**方法B: git clone（git を使える人向け）**

```powershell
git clone https://github.com/Shimooka-Norimasa/FastApiStudy.git
```

> 以降の説明では、教材を `C:\FastApiStudy` に置いたものとして書いています。
> 別の場所に置いた場合は、自分のフォルダの場所に読み替えてください。
> （ZIP で展開すると、フォルダ名が `FastApiStudy-main` になることがあります）

## 0-4. 仮想環境（venv）とは

Python のライブラリは、普通にインストールするとパソコン全体で共有されます。
プロジェクトごとに必要なバージョンが違うと困るので、**プロジェクト専用のライブラリ置き場** を作ります。これが **仮想環境** です。

```
パソコン全体の Python
 ├─ プロジェクトA の .venv … fastapi 0.100
 └─ プロジェクトB の .venv … fastapi 0.162   ← お互いに影響しない
```

## 0-5. 仮想環境を作る

PowerShell（またはコマンドプロンプト）で、教材のいちばん上のフォルダ（`README.md` がある場所）に移動して実行します。

```powershell
cd C:\FastApiStudy
python -m venv .venv
```

- `python -m venv` … Python に付属の「venv」機能を使う
- `.venv` … 作る仮想環境のフォルダ名（何でもよいが `.venv` が慣例）

仮想環境は **教材全体で1つ** です。章ごとに作る必要はありません。

## 0-6. 仮想環境を有効化する

```powershell
# PowerShell の場合
.venv\Scripts\Activate.ps1

# コマンドプロンプトの場合
.venv\Scripts\activate.bat

# Mac / Linux の場合
source .venv/bin/activate
```

成功すると、プロンプトの先頭に `(.venv)` と表示されます。

```
(.venv) PS C:\FastApiStudy>
```

> **PowerShell で「スクリプトの実行が無効」と言われたら**
> 次のコマンドを一度だけ実行してから、もう一度有効化してください。
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

> **注意:** ターミナルを開き直すたびに有効化が必要です。
> `(.venv)` が出ていない状態で `uvicorn` を実行すると「見つからない」エラーになります。
> 一度有効化すれば、`cd step02_fastapi` などで章のフォルダに移動しても有効なままです。
> 仮想環境から抜けたいときは `deactivate` と入力します。

## 0-7. ライブラリをインストールする

```powershell
pip install -r requirements.txt
```

`requirements.txt` には次の4つが書いてあります。

| ライブラリ | 役割 |
|---|---|
| `fastapi` | Web アプリを作るためのフレームワーク本体 |
| `uvicorn` | FastAPI のアプリを動かす Web サーバー |
| `jinja2` | HTML テンプレートエンジン |
| `python-multipart` | HTML フォームから送られたデータを読むのに必要 |

SQLite を使うための `sqlite3` は **Python に最初から入っている** ので、インストール不要です。

確認:

```powershell
pip list
```

一覧に `fastapi` `uvicorn` `Jinja2` `python-multipart` があれば準備完了です。

### 応用編で使うライブラリ（今は入れなくてよい）

応用編の第11章以降では、次のライブラリを追加で使います。
各章の中でインストール方法を説明するので、**基本編を進めている間は入れなくて大丈夫** です。

| ライブラリ | 使う章 | 役割 |
|---|---|---|
| `pytest` | 第11章〜 | 自動テストを実行する |

先にまとめて入れておきたい場合は、次のコマンドを実行します（基本編のライブラリも一緒に入ります）。

```powershell
pip install -r requirements-advanced.txt
```
