## 0-1. Python のバージョンを確認する

```powershell
python --version
```

`Python 3.10` 以上が表示されれば OK です（この教材は 3.12 で動作確認しています）。
`python` が見つからない、またはバージョンが古い場合は [付録 Python のインストール](付録_Pythonのインストール.md) を見てください。

> Mac では `python` の代わりに `python3` と入力します（仮想環境を有効化した後は `python` で動きます）。

## 0-2. 教材を `C:\FastApiStudy` に置く

この教材は、**`C:\FastApiStudy` に置いて使う** ことを前提に書かれています。
資料に出てくるコマンドもすべてこの場所を基準にしているので、必ずこの場所に置いてください。

次のどちらかの方法で用意します。

**方法A: ZIP でダウンロード（git を使ったことがない人向け）**

1. 教材の GitHub ページ（https://github.com/Shimooka-Norimasa/FastApiStudy ）を開く
2. 緑色の「**Code**」ボタン →「**Download ZIP**」を押す
3. ダウンロードした `FastApiStudy-main.zip` を右クリック →「**すべて展開**」を選ぶ
4. 展開先に **`C:\`** と入力して「展開」を押す → `C:\FastApiStudy-main` というフォルダができる
5. エクスプローラーで `C:\` を開き、`FastApiStudy-main` フォルダの名前を **`FastApiStudy`** に変える

**方法B: git clone（git を使える人向け）**

```powershell
cd C:\
git clone https://github.com/Shimooka-Norimasa/FastApiStudy.git
```

### 正しく置けたか確認する

エクスプローラーで `C:\FastApiStudy` を開き、**すぐ下に `README.md` と `docs` フォルダがある** ことを確認してください。

```
○ 正しい:  C:\FastApiStudy\README.md
× 間違い:  C:\FastApiStudy\FastApiStudy\README.md        ← フォルダが二重になっている
× 間違い:  C:\FastApiStudy\FastApiStudy-main\README.md   ← 同上
```

二重になっていたら、中のフォルダの中身を `C:\FastApiStudy` の直下に移してください。

> **Mac の場合**
> Mac には `C:\` がないので、ホームフォルダの `FastApiStudy`（`~/FastApiStudy`）に置き、
> 資料の `C:\FastApiStudy` を `~/FastApiStudy` に、`\` を `/` に読み替えてください。
> 例: `cd C:\FastApiStudy\step02_fastapi` → `cd ~/FastApiStudy/step02_fastapi`

## 0-4. 仮想環境（venv）とは

Python のライブラリは、普通にインストールするとパソコン全体で共有されます。
プロジェクトごとに必要なバージョンが違うと困るので、**プロジェクト専用のライブラリ置き場** を作ります。これが **仮想環境** です。

```
パソコン全体の Python
 ├─ プロジェクトA の .venv … fastapi 0.100
 └─ プロジェクトB の .venv … fastapi 0.162   ← お互いに影響しない
```

## 0-5. 仮想環境を作る

PowerShell（スタートメニューで「PowerShell」と検索）を開き、`C:\FastApiStudy` に移動して実行します。

```powershell
cd C:\FastApiStudy
python -m venv .venv
```

- `python -m venv` … Python に付属の「venv」機能を使う
- `.venv` … 作る仮想環境のフォルダ名（何でもよいが `.venv` が慣例）

仮想環境は **教材全体で1つ** です。章ごとに作る必要はありません。

## 0-6. 仮想環境を有効化する

```powershell
# PowerShell の場合
C:\FastApiStudy\.venv\Scripts\Activate.ps1

# コマンドプロンプトの場合
C:\FastApiStudy\.venv\Scripts\activate.bat

# Mac / Linux の場合
source ~/FastApiStudy/.venv/bin/activate
```

`C:\FastApiStudy` から始まる書き方なので、どのフォルダにいても有効化できます。

成功すると、プロンプトの先頭に `(.venv)` と表示されます。

```
(.venv) PS C:\FastApiStudy>
```

> **PowerShell で「スクリプトの実行が無効」と言われたら**
> 次のコマンドを一度だけ実行してから、もう一度有効化してください。
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

> **注意:** ターミナルを開き直すたびに有効化が必要です。
> `(.venv)` が出ていない状態で `uvicorn` を実行すると「見つからない」エラーになります。
> 一度有効化すれば、`cd C:\FastApiStudy\step02_fastapi` などで章のフォルダに移動しても有効なままです。
> 仮想環境から抜けたいときは `deactivate` と入力します。

## 0-7. ライブラリをインストールする

```powershell
cd C:\FastApiStudy
pip install -r requirements.txt
```

`requirements.txt` には次の4つが書いてあります。

| ライブラリ | 役割 |
|---|---|
| `fastapi` | Web アプリを作るためのフレームワーク本体 |
| `uvicorn` | FastAPI のアプリを動かす Web サーバー |
| `jinja2` | HTML テンプレートエンジン |
| `python-multipart` | HTML フォームから送られたデータを読むのに必要 |

SQLite を使うための `sqlite3` は **Python に最初から入っている** ので、インストール不要です。

確認:

```powershell
pip list
```

一覧に `fastapi` `uvicorn` `Jinja2` `python-multipart` があれば準備完了です。

応用編の第11章以降では、次のライブラリを追加で使います。

先にまとめて入れておきたい場合は、次のコマンドを実行します（基本編のライブラリも一緒に入ります）。

```powershell

```

> 第9章で使う **Pydantic** は、FastAPI と一緒に自動でインストールされています。
