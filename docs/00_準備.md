## 0-2. 仮想環境（venv）とは

Python のライブラリは、普通にインストールするとパソコン全体で共有されます。
プロジェクトごとに必要なバージョンが違うと困るので、**プロジェクト専用のライブラリ置き場** を作ります。これが **仮想環境** です。

```
パソコン全体の Python
 ├─ プロジェクトA の .venv … fastapi 0.100
 └─ プロジェクトB の .venv … fastapi 0.162   ← お互いに影響しない
```

## 0-3. 仮想環境を作る

PowerShell（またはコマンドプロンプト）で `FastApiStudy` フォルダに移動して実行します。

```powershell
cd C:\ClaudeCode\FastApiStudy
python -m venv .venv
```

- `python -m venv` … Python に付属の「venv」機能を使う
- `.venv` … 作る仮想環境のフォルダ名（何でもよいが `.venv` が慣例）

## 0-4. 仮想環境を有効化する

```powershell
# PowerShell の場合
.venv\Scripts\Activate.ps1

# コマンドプロンプトの場合
.venv\Scripts\activate.bat

# Mac / Linux の場合
source .venv/bin/activate
```

成功すると、プロンプトの先頭に `(.venv)` と表示されます。

```
(.venv) PS C:\ClaudeCode\FastApiStudy>
```

> **PowerShell で「スクリプトの実行が無効」と言われたら**
> 次のコマンドを一度だけ実行してから、もう一度有効化してください。
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

> **注意:** ターミナルを開き直すたびに有効化が必要です。
> `(.venv)` が出ていない状態で `uvicorn` を実行すると「見つからない」エラーになります。

## 0-5. ライブラリをインストールする

```powershell
pip install -r requirements.txt
```

`requirements.txt` には次の4つが書いてあります。

| ライブラリ | 役割 |
|---|---|
| `fastapi` | Web アプリを作るためのフレームワーク本体 |
| `uvicorn` | FastAPI のアプリを動かす Web サーバー |
| `jinja2` | HTML テンプレートエンジン |
| `python-multipart` | HTML フォームから送られたデータを読むのに必要 |

SQLite を使うための `sqlite3` は **Python に最初から入っている** ので、インストール不要です。

確認:

```powershell
pip list
```

一覧に `fastapi` `uvicorn` `Jinja2` `python-multipart` があれば準備完了です。

## まとめ

- 仮想環境 = プロジェクト専用のライブラリ置き場
- 作る: `python -m venv .venv` ／ 有効化: `.venv\Scripts\Activate.ps1`
- インストール: `pip install -r requirements.txt`
